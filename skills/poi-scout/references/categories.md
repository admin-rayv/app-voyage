# Catégories officielles App Voyage

7 catégories. Chaque POI reçoit 1-3 catégories.

| Slug | Emoji | Description | Exemples |
|------|-------|-------------|----------|
| `histoire` | 🏛️ | Patrimoine, personnages, événements passés | Maisons ancestrales, monuments, sites de batailles |
| `architecture` | 🏗️ | Styles notables, bâtiments uniques, infrastructure | Ponts, écluses, gares, styles architecturaux |
| `nature` | 🌿 | Parcs, sentiers, fleuve, arbres | Parcs municipaux, bord de l'eau, pistes cyclables |
| `food` | 🍴 | Restos, cafés, marchés, histoire culinaire | Restos iconiques, marchés fermiers, cafés historiques |
| `art` | 🎨 | Murales, galeries, spectacles, art public | Street art, sculptures, théâtres, bibliothèques |
| `insolite` | 👻 | Légendes, secrets, weird facts, hanté | Histoires de fantômes, tunnels, faits bizarres |
| `vie-locale` | 🏘️ | Marchés hebdo, events récurrents, traditions | Marchés du jeudi, festivals annuels, spots communautaires |
